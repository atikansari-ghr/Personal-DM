# Sharing documents

## Public links {#links}

People with **Share** permission can create a link to one document: open it → **Share → Public link**.

- The link opens only that document's **current version at the time of sharing** (pinned). A later renewal or new version is never substituted.
- Choose 1–90 days of validity; optionally add a password (at least 6 characters) and decide whether downloads are allowed.
- The full link is shown once. Only a hash is stored on the server.
- Password guessing is rate-limited.
- Links stop working when they expire, are revoked, when the document or its folder is archived, when the owner's account is disabled, or when the creator loses share permission.

The list under the share dialog shows status and how often each link was opened. Revoke any link at any time.

## Sharing a copy {#copies}

Downloading or sharing a file through your device creates an independent copy. Link expiry and revocation cannot recall copies that were already downloaded.
