# Search and saved views

## Full-text search {#search}

Type in the search bar at the top. Results are ranked by relevance across titles, details, tags and document text, with matching words highlighted. Suggestions appear as you type. Filter by owner, type, tag, status or expiry. Documents owned by others that you may open are listed under **Shared with me** (also a tile on the [Overview](overview.md)). Words that came only from OCR are found only while the document's OCR data exists; see [removing OCR data](ocr-corrections.md#remove).

## Saved views {#saved-views}

On a results page choose **Save view**. Saved views appear in the sidebar with a live count and can also be shown on the [Overview](overview.md).

## More like this {#similar}

On a document, the **More like this** tab lists documents sharing distinctive words, type, issuer or tags. It is a transparent text and metadata comparison — not AI.

## Privacy {#privacy}

Every result, highlight, count, suggestion and similar document respects your current permissions. If access is removed, results disappear immediately.
